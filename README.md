# CosmoLens – NASA Astronomy Picture of the Day

A sleek, responsive web application built with **Vite** and **Vanilla JavaScript** that fetches and displays NASA’s Astronomy Picture of the Day (APOD) using NASA’s official public API.

## Features

* 1. Automatically fetches today's space photo/video, title, and detailed explanation directly from NASA.
 
* 2.  Mobile-friendly layout (Responsive design).
 
* 3.  Able to navigate to previous dates to see the image of that day.
    
* 4. Able to select a random date and show the image of that day  
 

## Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES Modules)
* **Build Tool:** [Vite](https://vitejs.dev/)
* **API:** [NASA APOD API](https://api.nasa.gov/)
